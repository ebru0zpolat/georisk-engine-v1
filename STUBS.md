# Stubs inventory

Every synthetic / fallback / mock input that can affect scoring or financial outputs **must** appear here with a replacement plan. Unlisted stubs are a review fail (see `.cursor/rules/ci-stubs-honesty.mdc`).

Naming: prefer `stub_*` identifiers or `synthetic=true` on artifacts; methodology / data `source` should include `"synthetic calibration"` when values are not from a real calibrated source.
